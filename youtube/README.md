# 유튜브 채널 꾸미기 — FTS(에프티에스) @FTScm

채널: https://www.youtube.com/@FTScm (계정 nofood.hungryy) · 매일 06:00 IFTTT 가 아침 인사 쇼츠를 올린다(app34 `tools/shorts/IFTTT.md`).
채널 꾸미기는 유튜브 스튜디오에서 채널 주인이 한다 — IFTTT 는 영상 올리기만 되고, 유튜브 API 로도 프로필 사진 · 링크는 못 바꾼다.

## 파일
- `banner.png` 배너(2560×1440 · 6MB 아래) — `node youtube/banner.mjs` 로 다시 만든다(컨테이너 · 헤드리스 크롬 · Pretendard). 글자는 폰에서 보이는 가운데 칸(1546×423) 안이어야 하고, 넘치면 스크립트가 멈춘다.
- `preview-phone.png` · `preview-pc.png` · `preview-tv.png` — 기기마다 실제로 보이는 부분(검수용).
- 그림은 직접 그린 것만(해님이 · 구름 · 언덕). 토스 그래픽은 앱인토스 밖에서 쓰지 않는다.
- 다른 앱 영상이 이 채널에 같이 올라오게 되면 배너 문구(`banner.mjs TEXT`)와 아래 설명을 그때 바꾼다.

## 올리는 법(PC · 5분)
1. https://studio.youtube.com 에 채널 계정으로 들어가 왼쪽 **맞춤설정**.
2. **프로필**(또는 브랜딩) 탭 → 배너 이미지 **업로드** → 맥 `/Users/fulltimescam/fulltimescam/appintoss/ORG-SITE/youtube/banner.png` → 미리보기 그대로 **완료**.
3. 같은 화면 **설명**에 위 글 붙여 넣기 → **링크 추가**로 두 개.
4. 오른쪽 위 **게시**.
5. 왼쪽 아래 **설정 → 채널 → 기본 정보 → 키워드**에 위 줄 붙여 넣기 → **저장**.

프로필 사진(해님이)은 지금 그대로 둔다.
